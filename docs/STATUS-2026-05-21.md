## If anything is wrong with the live flow

- "Bad gateway secret" error: only happens on `?op=...` query-string calls. The browser-based upload uses `google.script.run` and doesn't need the secret. If you see this error from the UI, something deeper is wrong - check `src/AgreementUpload.js trdProcessUploadedAgreementBase64`.
- Claude extraction returns garbage: check that `TRD_CLAUDE_API_KEY` is set in Script Properties for whichever Google account is running the script.
- Drive folder taxonomy looks wrong (still shows old folders): re-deploy. The current v15 has the new taxonomy. If a previous deploy somehow stuck around, redeploy by:
  - Apps Script editor -> Deploy -> Manage deployments -> edit the deployment -> save (auto-bumps to latest version)
